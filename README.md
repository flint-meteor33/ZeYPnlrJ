# 项目简介

## 核心功能
- 基于 YOLOv8 的屋内护理行为检测系统，支持 5 类行为识别：Bending、Falling、Sitting、Sleeping、Standing
- 提供 9000 张数据集用于模型训练
- 支持多种输入源检测：单张图片、图片文件夹、视频文件、本地摄像头
- 实时显示目标位置、目标总数、置信度等信息
- 支持自定义置信度和 IOU 阈值设置
- 提供多种显示选项：标签、原图、检测模型选择
- 支持批量检测并直接查看所有检测结果
- 支持检测结果保存功能

## 适用场景
- 居家养老环境中的行为监测与安全防护
- 护理机构中的行为分析与管理
- 老年人活动状态监测与研究
- 家庭安全监控系统

## 技术特点
- 使用 Python 3.9 开发，依赖环境包括 opencv-python、PyQt5、ultralytics、torch1.9 等
- 提供完整源码、数据集、训练好的模型及训练结果
- 包含详细的项目运行教程和 UI 界面源文件
- 跨平台支持，可在 Pycharm+Anaconda 或 VSCode+Anaconda 环境中运行
